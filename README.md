# Electronic Shop

A fullstack e-commerce web application built using modern technologies.

## 🔹 Project Description
This is a fullstack application that allows users to browse products, register, log in, and interact with the system via API. The project implements core e-commerce functionality with a clear separation between frontend and backend.

## 🚀 Features
- User registration and authentication (JWT)
- Product catalog browsing
- Adding products
- API integration
- State management with Redux Toolkit

## 🛠️ Tech Stack
Frontend:
- React.js
- Redux Toolkit
- CSS Modules

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## 📁 Project Structure
- client/ — frontend (React)
- server/ — backend (Node.js + Express)
